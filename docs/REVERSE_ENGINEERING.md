## 反推假设

1. **创作端**：一条 prompt 进来，自动产出图 → 图生视频 → TTS 配音 → 字幕 → BGM → 合成成片。
2. **运营端**：成片自动多账号多平台分发，评论/DM 自动 LLM 回复，数据回流反哺 prompt 与选题池。
3. **运行形态**：n8n / LangGraph / Temporal 任意一种编排，背后队列驱动，前面有控制台。
4. **降级**：每个外部能力都有备选厂商，单家挂掉不影响整条流水线。

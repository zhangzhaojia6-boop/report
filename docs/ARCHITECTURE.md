# 架构

## 总览

```
                  ┌────────────────────────────────────────┐
                  │              apps/web (Next.js)        │
                  │  选题 / 脚本 / 素材 / 排期 / 评论 / 看板 │
                  └────────────────────────────────────────┘
                                  │ REST/RPC
                                  ▼
   ┌───────────────────────────────────────────────────────────────┐
   │                     apps/worker (Node)                        │
   │  消费队列：creative.* / publish.* / comment.* / metrics.*      │
   │  ┌──────────────────────────────────────────────────────────┐ │
   │  │           packages/orchestrator (LangGraph 风格)          │ │
   │  └──────────────────────────────────────────────────────────┘ │
   │           │                       │                       │   │
   │           ▼                       ▼                       ▼   │
   │  packages/adapters/image   /video   /tts        /publisher   │
   │  fal | replicate | mj       kling | veo | rw    x | yt | tt  │
   └───────────────────────────────────────────────────────────────┘
                  │                       │                  │
                  ▼                       ▼                  ▼
            Postgres                  Redis(队列)         MinIO/S3
```

## 关键约束

- **业务逻辑不进页面**：页面只调 BFF；BFF 调 orchestrator；orchestrator 调 adapters。
- **所有外部能力走适配器**：方便单家挂掉时降级到备选。
- **Prompt 是数据不是代码**：`packages/prompts/*.yaml`，热更新、版本化。
- **状态机即真相**：每条内容都有唯一状态，所有副作用都在状态切换时触发。
- **冷启动无密钥也能跑**：所有 adapter 都有 mock 实现。
